# Alienation PC v0.1.0

The first public release of the native PC port of Housemarque's **Alienation** (PS4) for Windows and Linux. The game's
own code runs on the PC through replacement PS4 system libraries and a Vulkan renderer derived from shadPS4.

**No game files are included.** You need your own decrypted Alienation PS4 package (`.pkg`); the launcher installs it.

## Downloads

| File | Platform |
| --- | --- |
| `AlienationPC-v0.1.0-windows-x64.zip` | Windows 10 (1903) or 11, 64-bit |
| `AlienationPC-v0.1.0-x86_64.AppImage` | Linux x86_64 (glibc 2.31 or newer) and Steam Deck, **experimental** |

Each has a `.sha256` file beside it. Both need a processor with AVX and LZCNT (Intel Haswell, AMD FX or newer) and a
Vulkan 1.3 driver.

- **Windows:** extract the ZIP into a folder you can write to (not Program Files), run `alienation.exe`, press
  **Install game...** on the Play page and select your `.pkg`.
- **Linux:** put the AppImage in a folder of its own, `chmod +x AlienationPC-v0.1.0-x86_64.AppImage`, run it and press
  **Install game...**. The game, saves and logs are kept beside the AppImage. FUSE is not required.
- **Steam Deck:** set it up in Desktop Mode as on Linux, then add the AppImage to Steam as a non-Steam game. Add
  `--launcher` to its Launch Options to open the launcher in Gaming Mode. See `docs/LINUX.md`.

## Supported game versions

| Build | Region | Notes |
| --- | --- | --- |
| CUSA00062 1.00 | EUR | base game |
| CUSA00062 1.06 | EUR | base game plus the official 1.06 update (**Install update...**), or the DUPLEX single-package repack, which runs as 1.06 |
| CUSA04430 1.00 | ASIA/KR | base game |

Other builds are refused with a message saying what was found.

## Major features

- Launcher: install your own package and the official update, remove the update, settings, Online, Trophies,
  Bug Report and a built-in updater
- Every supported build gets the same port features, each on its own verified patch sites

## Online co-op

- Two to four players over the Internet through the game's own squad menus; no PlayStation Network account
- Friends with Friend Codes, invitations in game and in the launcher (**Accept and play**), public rooms, Join
- Gameplay goes directly between the players' PCs; a relay is used automatically when they cannot connect directly
- Windows and Linux players play together; only the same game build meets (1.00, 1.06 with DUPLEX, and ASIA/KR are
  separate)
- The in-game network status box shows Online Off, Connecting, Connected or Unavailable

## Local co-op

Up to four controllers on **CUSA00062 1.06 and DUPLEX only**: press OPTIONS on another controller to join. CUSA00062
1.00 and CUSA04430 1.00 have no local co-op in the original game, and the port does not add it.

## Display and graphics

Render resolution (native to 4K), aspect ratio (16:9, 16:10, 21:9, 32:9, 4:3, 5:4), experimental True Ultrawide, SMAA,
FSR 1 with RCAS sharpening, texture filtering, VSync, window modes, monitor and graphics card selection. Alienation PC
v0.1.0 requires Vulkan.

## High frame rate

**Frame rate** (Gameplay page): 30, 60 (Original), 90, 120, 144, 165, 240 or Unlimited. The game always runs at its
original 60 frames a second, so gameplay speed, online play and local co-op never change. Above 60 the latest game frame
is shown again between new ones (repeated frames, no interpolation).

## Controllers

Xbox and PlayStation controllers and the keyboard; Xbox or PlayStation button prompts in every language, Korean,
Japanese and Chinese included. Menus confirm with Cross (A) by default; **Asian Menu Buttons** switches CUSA00062 1.06
and CUSA04430 to the Asian layout (Circle confirms, Cross cancels). Skip Intro, and Exit Game in the Options and Select
Campaign menus.

## Trophies and saves

Trophies (one set for every build) and save data per user, kept in the `user` folder beside the program (beside the
AppImage on Linux). Updating the port never touches the game, saves, settings or logs.

## Known issues

- **True Ultrawide:** mission map markers may be shown in the wrong place. Planned for v0.2.0.
- **Linux and Steam Deck are experimental.** The AppImage is built and checked headlessly (its libraries, glibc
  baseline, launcher start-up and data folder); real gameplay on Linux and on Steam Deck hardware, including online play
  and controllers in Gaming Mode, has not been tested yet.
- **High frame rates** above 60 repeat the latest game frame; they do not create new game frames. Under Gamescope (Steam Deck Gaming Mode) rates above the display's refresh may not
  show.
- **Local co-op** exists only on CUSA00062 1.06 and DUPLEX.
- **Online:** squads of three and four players are verified headlessly; two-player online games have been played.
  Leaderboards, weekly missions, leagues and the UNX Global Matrix features are unavailable.
- Allow overlay programs is Windows only.
