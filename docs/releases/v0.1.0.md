# Alienation PC v0.1.0

The first public release of **Alienation** (PS4) on PC, for Windows and Linux. The game's original x86-64 code runs
on your PC through replacement system libraries and a Vulkan renderer: the game you know, with PC options.

**No game files are included.** You need your own supported Alienation PS4 package (`.pkg`); the launcher installs it.

## Highlights

- **4K render resolution:** 480p, 720p, native 1080p, 1440p, 1800p and 4K. This is the game's internal render
  resolution, not just window scaling.
- **High frame rates, including 120 FPS:** 30, 60 (Original), 90, 120, 144, 165, 240 or Unlimited.
- **True Ultrawide** (experimental) with 21:9 and 32:9, plus 16:9, 16:10, 4:3 and 5:4.
- **Online co-op for up to 4 players** with friends, invites, direct P2P and relay fallback. No PlayStation Network
  account needed.
- **Local co-op for up to 4 players** on CUSA00062 1.06 and DUPLEX (see Supported game versions).
- **Windows** ZIP and **Linux** AppImage, Vulkan required. **Steam Deck** support is experimental.

## Graphics and display

- Render resolution: 480p, 720p, native 1080p, 1440p, 1800p, 4K
- Aspect ratio and True Ultrawide
- SMAA, FSR 1 with RCAS sharpening, texture filtering, VSync
- Windowed and Borderless Fullscreen (F11 switches), monitor and graphics card selection, GPU heap options
- FPS counter (F2), and frame rate and render resolution in the window title

**Frame rate** (Gameplay page): 30, 60 (Original), 90, 120, 144, 165, 240 or Unlimited. The game itself keeps running at
its original 59.94/60 Hz, so gameplay speed, online play and local co-op never change. Above 60 the latest game frame is
shown again between new ones; this is **not** motion interpolation, and the game does not simulate at 120/144/240 Hz.

Vulkan is the only renderer in v0.1.0: Alienation PC v0.1.0 requires Vulkan (a Vulkan 1.3 driver).

## Multiplayer

**Online co-op, 2 to 4 players**, through the game's own squad menus:

- Friends with Friend Codes, and invitations in game and in the launcher (**Accept and play**)
- Public rooms with Join, and an online status box in game
- Gameplay goes directly between the players' PCs (P2P); a relay is used automatically when they cannot connect directly
- Windows and Linux players play together. Only the same game build meets: 1.00, 1.06 (with DUPLEX) and ASIA/KR are
  separate
- Not compatible with PlayStation Network or official servers

**Local co-op, up to 4 players:** connect up to four controllers and press OPTIONS on another controller to join. Each
player has their own class, gear and save. Available **only on CUSA00062 1.06 and DUPLEX**: CUSA00062 1.00 and
CUSA04430 1.00 have no local co-op in the original game, and the port does not add it.

## Gameplay and quality of life

- Skip Intro
- Exit Game in the Options and Select Campaign menus
- Xbox controller prompts in every language, Korean, Japanese and Chinese included
- **Asian Menu Buttons** option (Circle confirms, Cross cancels) for CUSA04430 and CUSA00062 1.06
- Portuguese voice-language text correction on ASIA/KR
- Trophies and save data per user
- Xbox and PlayStation controllers, multiple controllers and keyboard
- Built-in updater: updates are always started by you, and the game, saves and settings are never touched

## Supported game versions

| Build | Region | Notes |
| --- | --- | --- |
| CUSA00062 1.00 | EUR | base game |
| CUSA00062 1.06 | EUR | base game plus the official 1.06 update (**Install update...**) |

The USA release (CUSA04181) is not supported. Other builds are refused with a message saying what was found.

## Windows

`AlienationPC-v0.1.0-windows-x64.zip`: Windows 10 (1903) or 11, 64-bit, Vulkan 1.3 driver, a processor with AVX and
LZCNT (Intel Haswell, AMD FX or newer). Updates go through `trg-updater.exe`.

## Linux and Steam Deck

`AlienationPC-v0.1.0-x86_64.AppImage`: x86_64, Vulkan required, built on an Ubuntu 20.04 / glibc 2.31 baseline.

- If FUSE is unavailable, the AppImage automatically falls back to extract-and-run
- The game, saves, settings and logs are kept beside the AppImage, not inside it
- The AppImage updates itself in place
- **Steam Deck (experimental):** Vulkan, Gamescope detection and controller-friendly launcher navigation. Add the
  AppImage to Steam as a non-Steam game and put `--launcher` in its Launch Options to open the launcher in Gaming Mode.
  See `docs/LINUX.md`

## Known issues

- **True Ultrawide:** mission map markers may be shown in the wrong place. Planned for v0.2.0.
- **Frame rates above 60** repeat the latest game frame; they do not create new game frames. Under Gamescope (Steam Deck
  Gaming Mode) rates above the display's refresh may not show.
- **Local co-op** exists only on CUSA00062 1.06 and DUPLEX.
- **Linux and Steam Deck** have had much less real-hardware testing than Windows. The AppImage is checked headlessly;
  real gameplay on Steam Deck hardware, including online play and controllers in Gaming Mode, has not been tested yet.
- **Online:** two-player games have been played; squads of three and four players are verified headlessly and have had
  less manual testing. Leaderboards, weekly missions, leagues and the UNX Global Matrix features are unavailable.
- Allow overlay programs is Windows only.

## Installation

Each download has a `.sha256` file beside it.

- **Windows:** extract the ZIP into a folder you can write to (not Program Files), run `alienation.exe`, press
  **Install game...** on the Play page and select your `.pkg`.
- **Linux:** put the AppImage in a folder of its own, `chmod +x AlienationPC-v0.1.0-x86_64.AppImage`, run it and press
  **Install game...**.
- **Steam Deck:** set it up in Desktop Mode as on Linux, then add the AppImage to Steam as a non-Steam game.
